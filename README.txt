ניו יורק – מידע למטייל
=======================
יוצר: יעקב זוהר
גרסה: 20261114-01

איך להפעיל כ-PWA
----------------
1. העלו את כל תיקיית nyc-pwa לשרת HTTPS (או localhost).
2. פתחו index.html בדפדפן.
3. בדפדפן תומך: "התקן אפליקציה" / Add to Home Screen.
4. Service Worker (sw.js) מאפשר שימוש חלקי גם בלי רשת.

קבצים
-----
index.html     – האפליקציה המלאה
manifest.json  – הגדרות PWA
sw.js          – Service Worker
icons/         – אייקונים (פסל החירות + סקייליין)

HTML עצמאי
----------
אפשר לפתוח את NewYork_Guide_Standalone.html ישירות מהמחשב.
חלק מהתכונות (מפת רקע, מזג אוויר, תמונות, PWA) דורשות חיבור לאינטרנט.

תכונות עיקריות שנוספו/חוזקו בגרסה זו
------------------------------------
• כפתור "מה עושים היום" – לפי מזג אוויר, יום בשבוע ומסלול שמור
• "בחר מקום במפה" – בחירה לפי קטגוריה + מיקוד במפה + מסלול הגעה
• מסך מלא למפת העיר ולמפת המטרו
• טבלת ביטויים שימושיים באנגלית עם הגייה והשמעה (TTS)
• תחזית מזג אוויר גם בתוך ימי המסלול (כשיש תאריכים)
• אייקון אופייני לניו יורק, manifest ו-Service Worker
